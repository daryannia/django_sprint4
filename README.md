# Блогикум — учебный проект социальной сети

Учебный проект, выполненный в рамках курса от Яндекс.Практикум. Это упрощённая социальная сеть для ведения личных дневников с полным набором функций для публикации, комментирования и управления контентом.

## Основные возможности

### Управление пользователями
- **Регистрация** новых пользователей
- **Авторизация** и аутентификация
- **Личный кабинет** с информацией о пользователе
- **Смена пароля** и восстановление доступа
- **Просмотр всех постов** конкретного автора

### Работа с постами
- **Создание, редактирование и удаление** постов
- **Отложенная публикация** (планирование постов)
- **Прикрепление изображений** к публикациям
- **Теги и локации** для категоризации
- **Пагинация** ленты записей

### Система комментариев
- **Добавление комментариев** к любым постам
- **Редактирование и удаление** своих комментариев
- **Пагинация и сортировка** комментариев по дате
- **Модерация** комментариев администратором

### Администрирование
- **Управление пользователями** и правами доступа
- **Создание тегов и локаций** (только для администраторов)
- **Публикация/снятие с публикации** любых постов
- **Управление комментариями**

## Технические особенности

### Безопасность и обработка ошибок
- **Кастомные страницы ошибок**: 403 CSRF, 404, 500
- **Защита от CSRF-атак**
- **Проверка прав доступа** для всех операций

### Пользовательский интерфейс
- **Адаптивный дизайн** с использованием Bootstrap
- **Интуитивная навигация**
- **Удобные формы** для всех действий
- **Подтверждение удаления** записей

### Пагинация и сортировка
- **Пагинация постов** на главной странице
- **Пагинация комментариев**
- **Сортировка комментариев** по дате добавления
- **Отображение постов автора** с пагинацией

## Используемые технологии

### Основной стек
- **Python 3.9+** — основной язык программирования
- **Django 4.0+** — веб-фреймворк
- **SQLite** — база данных (для разработки)

### Frontend
- **HTML5** — разметка страниц
- **CSS3** — стилизация
- **Bootstrap 5** — фреймворк для адаптивного дизайна

### Дополнительные инструменты
- **Pillow** — работа с изображениями
- **unittest/pytest** — тестирование
- **flake8** — линтинг кода
- **BeautifulSoup** — парсинг HTML в тестах
