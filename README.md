**Blogicum** — учебный проект блог-платформы на Django (четвёртый спринт).

## Основные характеристики
- Полноценное веб-приложение на Django с шаблонами HTML
- Готовая структура с тестами (pytest) и тестовыми данными
- Чистая архитектура MVT (Model-View-Template)
- Работающий бэкенд с фикстурами для быстрого старта
